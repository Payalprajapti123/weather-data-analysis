# 🌤️ Weather Data Analysis & Prediction

## 📌 Project Overview

This project is a Weather Data Analysis and Prediction System developed using Python and Machine Learning.

The system analyzes weather data and predicts the weather condition based on Temperature, Humidity, Pressure, Wind Speed, and Rainfall.

## 🚀 Features

- Weather data analysis
- Temperature trend visualization
- Humidity trend visualization
- Rainfall trend visualization
- Machine Learning based weather prediction
- Interactive Streamlit web application
- User-friendly weather prediction interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Jupyter Notebook

## 🤖 Machine Learning Model

The project uses a Random Forest Classifier for weather prediction.

### Input Features

- Temperature
- Humidity
- Pressure
- Wind Speed
- Rainfall

### Output

The model predicts the weather condition such as:

- Sunny
- Rainy
- Cloudy
- Other weather conditions available in the dataset
